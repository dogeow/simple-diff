# 2026-09-08 改进记录

## 修正范围

- 关闭会话、重比、更换来源和窗口关闭共用未保存检查；支持保存后继续、放弃、取消，保存失败不继续。
- 会话切换保留草稿和原内容，持久化保留所有未保存文件；恢复时重新计算差异，避免将整份 Diff 对象写入 localStorage。
- 保存检测外部修改并防止同一文件侧重复提交；对比启动和局部重扫丢弃已失效的异步结果。
- 修正右侧目录列顺序；每个可调宽面板独立收起次要列，优先保留文件名。切换或关闭会话清理旧选择。
- 文件和文本 Diff 使用至多两个 Worker，取消会终止计算；合并编辑支持撤销、重做及文件内查找。
- 行对齐改为保持原有平局规则的 Fenwick 索引；字符比较使用内存和计算预算。大块 Diff 按行裁剪，同时保留整块应用的完整范围。
- 同步修复重复加锁及暂停过程中清除、替换任务的竞态；进度使用增量条目，队列分页，传输提供字节进度。
- 文件写入和同步使用临时文件替换；SFTP 使用 OpenSSH 原子覆盖扩展。所有独立 SSH 连接在认证前验证主机密钥。

## 性能样例

本机 Node 单次对照，不代表跨硬件或真实远程端到端耗时：

| 样例 | 修正前 | 修正后 |
| --- | ---: | ---: |
| 20,000 条独立文本行，将后半块移动到前面 | 539.0 ms | 20.0 ms |
| 两侧各 4,000 个完全不同字符 | 约 155.6 ms、124 MB 堆增量 | 0.45 ms、0.23 MB 堆增量 |
| 100,000 行相同内容后接一行差异，600 px 视口 | 100,001 行进入渲染 | 45 行进入渲染 |

对 400 组确定种子的短文本重排样例，改进后的行对齐结果与原实现一致。大块无锚点文本允许按计算预算采用较粗的配对；文本内容和行号保持完整。

## 回归覆盖与边界

- Vitest 覆盖取消、保存失败、后台草稿恢复、关闭整个会话、Worker 并发和取消、过期 Diff 结果、撤销及同步增量合并。
- Rust 覆盖原文件保留、固定缓冲区、同步状态转换及 SFTP 数据包边界；真实 OpenSSH 测试覆盖认证前拒绝和实际 SFTP 写入。
- 浏览器预览复测 800×600 和标准窗口下的目录布局、文件合并、关闭保护、撤销及查找。
- 浏览器使用模拟文件后端；真实远程生产服务器、应用签名发布、跨平台文件系统行为和已运行的 GitHub CI 不属于本机验证结论。
- 保存前的外部修改检查属于乐观检查；不提供与其他程序共享的写锁。磁盘空间、权限、SSH 连接故障和不支持原子覆盖的 SFTP 服务仍会返回具体错误。
